# M Putra Alif Syah — Portfolio

Personal portfolio website built with **Treto** theme, featuring Japanese-inspired aesthetics and Y2K retro-digital design elements.

🌐 **Live:** [putraAlifSyah.github.io/putra-portfolio](https://putraAlifSyah.github.io/putra-portfolio)

---

## ✨ Features

- **One-page scroll** — Smooth full-page navigation with dot pagination
- **Multi-language** — Toggle between English, Indonesia, 日本語, 한국어
- **Japanese aesthetics** — Kanji watermarks, torii-gate accents, enso-inspired elements
- **Y2K retro-digital** — Space Mono typography, geometric shapes, scan-line overlays
- **Responsive** — Works on desktop, tablet, and mobile
- **Portfolio gallery** — Filterable project grid with lightbox
- **Testimonials slider** — Client feedback carousel
- **Blog section** — Latest posts showcase
- **Contact form** — With validation

---

## 📂 Structure

```
├── index.html          # Main one-page portfolio

│   └── plugins/        # Bootstrap Grid, Swiper, Magnific Popup
├── js/
│   ├── main.js         # Core functionality
│   ├── lang.js         # Multi-language toggle system
│   └── plugins/        # jQuery, Swiper, Isotope, Onepage
├── fonts/              # Font Awesome icons
├── img/
│   ├── faces/          # Profile & client photos
│   ├── portfolio/      # Project screenshots
│   └── blog/           # Blog post images
└── scss/               # SCSS source files
```

## 🎨 Design Concept

Kombinasi tiga elemen:
1. **Treto Theme** — Clean, modern portfolio layout with geometric borders
2. **Japanese (和風)** — Kanji watermarks (技・人・能・学・歴・務・作・声・記・繋), vermillion accents, subtle patterns
3. **Y2K Retro-Digital** — Monospace typography, bracket-style headings, scan-line textures, sharp geometric shapes
