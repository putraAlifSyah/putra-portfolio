# putra-portfolio

Personal portfolio website. Built with Treto theme, Japanese-inspired aesthetics, and Y2K retro-digital design.

## Features

- One-page scroll navigation with dot pagination
- Multi-language support (EN, ID, JP, KR)
- Filterable portfolio gallery with lightbox
- Testimonials slider
- Blog section
- Contact form with validation
- Responsive design

## Tech Stack

- HTML5 / CSS3 / SCSS
- jQuery
- Swiper.js
- Isotope.js
- Magnific Popup
- Font Awesome
- Google Fonts (Jost, Noto Sans JP, Space Mono)

## Design

Kombinasi tiga elemen:
- **Treto Theme** — Clean portfolio layout with geometric borders
- **Japanese** — Kanji watermarks, vermillion accents
- **Y2K Retro-Digital** — Monospace typography, geometric shapes, scan-line textures
